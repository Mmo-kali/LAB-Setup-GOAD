# 🧪 OSCP Lab Environment — Proxmox + GOAD + VPN Setup

This repo documents the custom lab environment created by [Michael Nolk](https://www.linkedin.com/in/michaelnolk/) and [Orlando Companioni](https://www.linkedin.com/in/orlando-companioni/) for OSCP exam preparation.

## 🛠️ Key Features:
- **Proxmox Server** hosting multiple virtual machines and services
- **GOAD Lab** simulating a real-world Windows Active Directory environment
- **Bare Metal Kali Linux** attack machine
- **VPN Access** for secure remote collaboration across different LANs
- **Dual-boot system** (Windows/Kali) for direct access and testing flexibility
- **VirtualBox + Vagrant/Docker/pyenv** to automate the GOAD deployment process

## 📡 Access Architecture:
- VPN tunnel connects remote systems to the Proxmox server on a private LAN
- SSH access to Kali Linux and Windows-based GOAD environment for realistic pentesting scenarios

## 🧠 Purpose:
Hands-on preparation for the **Offensive Security Certified Professional (OSCP)** exam, focusing on offensive techniques, AD exploitation, and real-world attack simulation.
